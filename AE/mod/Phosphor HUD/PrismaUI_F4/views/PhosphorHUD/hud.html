            What shows where

            Your plugin passes along which game menus are open, plus a few flags (power armor, iron sights, animation scenes, photo mode, HUD toggled off). Phosphor turns that into one situation, using the highest one in this list, and shows, dims or hides each part of the HUD. Every row can be overridden from Phosphor's settings page. The highlighted row is the situation the preview is in now.

            ● shown◐ dimmed· hidden
            Wiring it into PrismaUI F4

            Out of combat the vitals, compass and weapon panel sit at half opacity and brighten for five seconds whenever their values change. In combat everything stays lit. Active effect timers never dim, and they blink through their last ten seconds. When the page loads inside the game (file:// or the Ultralight renderer) the preview scene and these controls hide and the background turns transparent.

            The cores work like Red Dead Redemption 2's: the ring is the stat, and food, water and rest drain inside their icons. Radiation takes a red bite out of the end of the HP ring, the same way it lowers max HP in game. A gold ring means a chem is boosting that core: Buffout on HP, Nuka-Cola or Jet on AP, Rad-X on RAD.

            Companion portraits come from Companion Status UI Remastered and load from the portraits folder next to hud.html, so this hosted preview shows plain icons instead. To see them, open hud.html#preview from that folder in a browser.

            All updates go through one global, hudUpdate(json), so your F4SE plugin only needs to send one string per tick. Every field is optional. The C++ side below is pseudo-code; match the call names to the PrismaUI F4 API you have installed.

            // F4SE plugin, PrismaUI F4 API (PrismaUI_F4_API.h, interface V10+)
auto* prisma = PRISMA_UI_API::RequestPluginAPI<PRISMA_UI_API::IVPrismaUI12>();
view = prisma->CreateView("PhosphorHUD/hud.html", OnDomReady);   // path is relative to PrismaUI_F4/views
prisma->SetViewRole(view, PRISMA_UI_API::ViewRole::kWidget);     // never counts as "a panel in the way"

// every update is one JSON string handed to the page's global hudUpdate()
prisma->InteropCall(view, "hudUpdate", R"({"snapshot":true,"hp":212,"hpMax":310,"ap":64,"apMax":90,"rads":140,
  "heading":27,"clip":9,"reserve":216,"weapon":"10mm Pistol","grenades":8,
  "needs":{"food":0.7,"water":0.45,"rest":0.25},"limbs":{"lleg":0.3}})");
// in game the HUD stays invisible until the first message with "snapshot":true (or hp).
// activation prompt: key from GetButtonPrompt("Activate"), text from the game's activate label; null hides it
//   InteropCall(view, "hudUpdate", R"({"prompt":{"key":"E","text":"Talk to Piper","hold":false}})");
// after a save loads send {"reset":true} and then a fresh snapshot.
// limbs: each condition value / 100 (PerceptionCondition, EnduranceCondition, Left/RightAttackCondition,
// Left/RightMobilityCondition). 0 = crippled. The figure hides when every limb is healthy.
// figure: silhouette | vaultboy | vaultgirl (from the MCM "Limb figure" setting; resolve Auto in the plugin
// from Condition Boy's iCharacterType). gear: which layer each part uses, refreshed on equip/unequip.
hudUpdate('{"figure":{"type":"vaultgirl","hideHealthy":true}}')
hudUpdate('{"gear":{"clothed":true,"armor":{"torso":true,"larm":true,"rarm":false}}}')

// events: fire once
hudUpdate('{"notify":{"text":"Purified Water","sub":"+1  ·  WT 1.0","kind":"item"}}')
hudUpdate('{"quest":{"eyebrow":"Quest started","title":"Signal in the Static",
            "objectives":[{"t":"Find the source of the broadcast"}]}}')
hudUpdate('{"target":{"name":"Raider Psycho","level":14,"pct":0.6,"legendary":true}}')
hudUpdate('{"loot":{"name":"Wooden Crate","items":[{"n":"Duct Tape","q":1}],"sel":0}}')
hudUpdate('{"subtitle":{"who":"Settler","line":"Water pump is running again."}}')
hudUpdate('{"combat":true, "xpGain":35, "radsGain":12}')

// compass markers: b = bearing in degrees from north (atan2(dx, dy) of target minus player),
// dist in meters, dz = height difference. Door = objective is behind a load door.
hudUpdate('{"markers":[
  {"id":"q1","t":"door","b":42,"dist":142,"dz":12,"label":"Relay Tower","active":true},
  {"id":"q2","t":"quest","b":200,"dist":1830,"label":"Salt and Rust","active":false},
  {"id":"v111","t":"vault","b":-68,"dist":780,"label":"Vault 111","disc":true},
  {"id":"e1","t":"enemy","b":118}]}')
hudUpdate('{"marker":{"id":"q1","t":"quest","dist":38,"dz":-9}}')   // update one by id
hudUpdate('{"markerRemove":"q2"}')
// t: quest door settlement city cave vault factory landmark pin enemy ally
// tracked quests stay pinned to the compass edge with an arrow when behind you;
// face any labeled marker to see its name and distance under the heading

// quest tracker (replaces Active Quest HUD): resend the whole tracker when anything changes.
// Objectives are matched by text, so a newly done one gets a check and a new one slides in.
hudUpdate('{"tracker":{"title":"Signal in the Static","objectives":[
  {"t":"Reach the relay tower","done":true},{"t":"Get inside the relay tower","dist":142}],
  "others":["Salt and Rust"]}}')
hudUpdate('{"tracker":null}')        // nothing tracked

// companions (replaces Companion Status + its UI Remastered skin; works with Liga's 16-person team)
// type: human dog robot mutant · affinity -1000..1000 or null · state: following waiting downed
// portraits: tries a base companion (piper, nick, preston, maccready, danse, cait, codsworth, deacon, dogmeat,
// hancock, x6-88), then portraits/.svg, then each 3+ letter word; "portrait":"portraits/file.svg" overrides
hudUpdate('{"party":[{"name":"Piper","affinity":780},{"name":"Dogmeat","type":"dog"},
            {"name":"Nick Valentine","hp":0.6,"affinity":910}]}')      // whole team, in order
hudUpdate('{"companion":{"name":"Piper","hp":0,"state":"downed"}}')   // add or update one member
hudUpdate('{"companionRemove":"Dogmeat"}')
hudUpdate('{"companionReact":{"name":"Piper","kind":"liked"}}')   // loved | liked | disliked | hated
// rank labels default to Idolized 1000, Admiration 750, Confidant 500, Neutral 0, Disdain -500;
// send "rank":"..." to override with the game's own value

// clock (replaces HoloTime): send GameHour once, the HUD advances it locally
hudUpdate('{"time":{"hour":21.7,"timescale":20,"h24":false}}')

// explosives: read the player's equipped throwable (works for vanilla and Explosives Cycler,
// which just equips items into the same slot). A new item flashes its full name, a lower count
// plays the throw tick, 0 shows red "00" and folds the row away.
hudUpdate('{"explosive":{"name":"Plasma Grenade","short":"PLSM","count":2}}')
hudUpdate('{"explosive":null}')    // nothing equipped: the grenade row hides
hudUpdate('{"flashlight":true}')    // Pip-Boy light on: the lamp row shows under the ammo

// settings: forward Phosphor's MCM values once at load and whenever MCM closes (see 04_SETTINGS.md in the handoff)
hudUpdate('{"settings":{"limbFigure":"vaultboy","hideHealthyFigure":true,"armorPieces":true,"showWeight":"near","showAdrenaline":true,"needStageNames":true,"survivalEnemyMarkers":false,"mineWarnings":true,"mineCompass":true,"karmaReadout":true,"localReputation":true,"challengeTracker":true,"mutationNotices":"bar","legendaryDropMarkers":true,"levelUpBanner":true,"perkReminder":true,"contextRules":{"scope":"recommended"}}}')
hudUpdate('{"notify":{"text":"Purified Water","sub":"+1","kind":"item","icon":"bottle"}}')   // icon optional

// leveling: xpGain does the whole moment (bar rollover, banner, perk reminder). perkPoints/skillPoints keep the
// reminder in sync with the game; perkKey is LevelUpMenuEx's "Open LevelUpMenu" hotkey; skillsPerLevel if its skills are on.
hudUpdate('{"xpGain":150}')
hudUpdate('{"perkPoints":1,"skillPoints":15,"perkKey":"K","skillsPerLevel":15}')
hudUpdate('{"levelUp":{"from":23,"to":24,"perks":1,"skills":15}}')   // when the game reports the level directly

// legendaries: mutations the plugin reads off the targeted enemy (Immersive Legendary Mutations effects); heal = share
// of health regained. Feed notices are off unless mutationFeed is true, to keep the mutations mod's silence.
hudUpdate('{"target":{"name":"Legendary Raider Veteran","level":28,"pct":0.6,"legendary":true,"mutations":[{"name":"Ballistic hide","kind":"defense"}]}}')
hudUpdate('{"targetMutated":{"name":"Healing factor","kind":"heal","heal":0.25}}')    // kind: offense | defense | heal
hudUpdate('{"legendaryLoot":{"id":"ff0a12","dropped":true,"item":"Combat Rifle","effects":["Two Shot"],"b":40,"dist":12}}')
hudUpdate('{"legendaryLoot":{"id":"ff0a12","picked":true,"item":"Combat Rifle","effects":["Two Shot"]}}')
hudUpdate('{"weaponLegendary":["Bloodied","Explosive"]}')
hudUpdate('{"crosshair":{"spread":34}}')   // the game's crosshair radius in stage px (null = default)   // LEO effects on the equipped weapon (up to 5)

// karma (KARMA): value from KARM_KarmaValueGlobal; alignment is worked out (+/-250, +/-750) unless sent;
// title is the mod's level-dependent title. change + reason post a feed item (pair with "Explain My Choices").
hudUpdate('{"karma":{"value":380,"title":"Defender","change":15,"reason":"Healed a settler"}}')
// reputation (REPUTATION): event = discovered | fameGained | fameLost | infamyGained | infamyLost | hitSquad | gift
hudUpdate('{"reputation":{"faction":"Diamond City","title":"Liked","event":"fameGained"}}')
hudUpdate('{"location":"Diamond City","region":"Commonwealth","faction":"Diamond City"}')   // shows your standing there
// challenges (CHALLENGES): the ones the player tracks in the Pip-Boy tab
hudUpdate('{"challenges":[{"id":"hitdeck","name":"Hit the Deck","cur":31,"max":50}]}')
hudUpdate('{"challengeComplete":{"id":"hitdeck","name":"Hit the Deck","reward":"Perk: Hit the Deck","xp":0}}')

// mines: send ~10-20x a second while any mine is counting down at the player (what Mine Detector HUD detects).
// x/y are stage pixels (1920x1080) from projecting the mine's position; off-screen mines send onScreen:false and a
// bearing relative to the camera (0 = straight ahead, 90 = right) instead. b = compass bearing for a compass marker.
hudUpdate('{"mines":[{"id":"ff012a","name":"Frag Mine","x":905,"y":792,"dist":5,"left":2.1,"total":4.5,"disarm":true,"b":31}]}')
hudUpdate('{"mines":[],"mineExploded":"ff012a"}')   // plays the blast at its last position

// settlement attacks (SKK Settlement Attack System or vanilla): b/dist place a pulsing defend marker on the compass.
// state: pending (on the way) -> active (fighting) -> won | lost (didn't make it) | ended (called off)
hudUpdate('{"settlementAttack":{"id":"abernathy","name":"Abernathy Farm","faction":"Raiders","total":12,"defense":85,"state":"pending","b":118,"dist":1320,"vertibird":false}}')
hudUpdate('{"settlementAttack":{"id":"abernathy","state":"active","remaining":7}}')
hudUpdate('{"settlementAttack":null}')

// survival: on/off from the game's difficulty; fatigue is the share of max AP lost (0-1), shown like rads on HP.
// stages optional (0-5 per need), otherwise picked from the 0-1 values. Enemy dots stay off the compass in survival.
hudUpdate('{"survival":{"on":true,"fatigue":0.18,"adrenaline":{"rank":4,"kills":2,"perRank":5,"bonus":"+20% dmg"}}}')
hudUpdate('{"weight":{"cur":286,"max":300}}')          // shows near the limit; red and "Overweight" past it
hudUpdate('{"illness":{"id":"parasites","hoursLeft":120}}')   // fatigue infection insomnia lethargy parasites weakness
hudUpdate('{"cure":true}')                               // antibiotics or a doctor: clears every illness
hudUpdate('{"effect":{"id":"wellrested","name":"Well Rested","kind":"med","icon":"bed","hours":8}}')  // game-time effect

// context: send whenever a menu opens or closes, with the full list of open menus.
// Phosphor picks the highest situation (see "What shows where") and fades each part of the HUD.
hudUpdate('{"context":{"menus":["ScopeMenu"],"powerArmor":false,"ads":false,"scene":false,"photo":false,"hudHidden":false}}')
hudUpdate('{"context":{"prismaFocus":true}}')   // another PrismaUI page (Gunsmith, Locker, MAP76...) has focus
hudUpdate('{"context":{"rules":{"scope":"hide","powerarmor":"recommended"}}}')   // from the MCM page

// stealth: send while the player is sneaking. level is 0-100 (highest detection on the player);
// state is optional and overrides the level thresholds (hidden <20, caution <50, danger <85, detected)
hudUpdate('{"stealth":{"sneaking":true,"level":35}}')
hudUpdate('{"stealth":{"sneaking":false}}')

// active effects: add or refresh by id; the ring counts down locally
hudUpdate('{"effect":{"id":"psycho","name":"Psycho","kind":"chem","icon":"bolt",
            "duration":480,"remaining":480,"desc":"+25% damage · +50 DR"}}')
hudUpdate('{"effectRemove":"psycho"}')
hudUpdate('{"effects":[ ... ]}')   // full list, resyncs every timer (e.g. after a load)
hudUpdate('{"paused":true}')       // freeze timers while menus are open
// kind: chem | med | drink | bad    icon: bolt shield hourglass dumbbell capsule syringe bottle warn
// duration 0 = no timer (addictions, permanent buffs)
