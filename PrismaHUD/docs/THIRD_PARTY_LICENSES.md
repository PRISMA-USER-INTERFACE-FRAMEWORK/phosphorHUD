## Controller button prompts — shipped by the framework

PrismaHUD renders controller button art through the PrismaUI framework's V9 controller API, but does
**not** bundle the art itself — the framework ships it (Julio Cacko "Free Input Prompts", CC-friendly
free terms). See the framework's `THIRD_PARTY_ASSETS.md` for the attribution. Credit:
**"Input prompt art by Julio Cacko (juliocacko.itch.io/free-input-prompts)."**
